# Remediation Roadmap

## 0-30 days: Stabilise high-risk compliance gaps

- Appoint data protection lead/DPO if required.
- Create data protection risk register.
- Review and update privacy notices.
- Start ROPA/data inventory.
- Enable MFA for email, admin and remote access.
- Create breach response checklist and breach log.
- Identify critical suppliers and processor contracts.

## 31-60 days: Build repeatable governance

- Complete ROPA for core data processes.
- Complete data sharing map.
- Review data sharing agreements.
- Introduce DPIA screening for new systems and CCTV.
- Define vulnerability scanning and patching SLA.
- Create retention schedule.
- Run staff training on data protection and incident reporting.

## 61-90 days: Evidence, assurance and continuous improvement

- Complete supplier due diligence for high-risk suppliers.
- Perform sample access review for care records and HR systems.
- Test backup and restore process.
- Complete vulnerability remediation report.
- Run breach tabletop exercise.
- Produce management dashboard.
- Review residual risks and risk acceptance.
