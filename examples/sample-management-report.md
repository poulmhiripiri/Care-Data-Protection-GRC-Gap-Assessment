# Sample Management Report

## Executive summary

The assessment identified that the care provider has several informal data protection practices in place, but governance evidence is inconsistent. The highest-risk areas are incomplete records of processing, weak DPIA screening, incomplete supplier assurance, and lack of formal vulnerability management.

## Top recommendations

1. Complete a Record of Processing Activities and data flow map.
2. Update privacy notices for service users, families and staff.
3. Implement DPIA screening for new projects, suppliers, CCTV and digital care record changes.
4. Build a supplier register and review processor contracts.
5. Enable MFA and formalise access reviews.
6. Create vulnerability scanning, patching and remediation SLA process.
7. Create retention schedule and secure disposal log.

## 90-day roadmap

### 0-30 days

- Appoint owner for each compliance gap.
- Enable MFA for all remote/cloud access.
- Create breach log and risk register.
- Start ROPA and privacy notice update.

### 31-60 days

- Complete data sharing map.
- Review top 10 high-risk suppliers.
- Implement DPIA screening.
- Define vulnerability management SLA.

### 61-90 days

- Complete policy refresh.
- Run staff awareness training.
- Conduct access review.
- Produce board-level compliance dashboard.
