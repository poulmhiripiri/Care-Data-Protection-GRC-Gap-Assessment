# Example Care Provider Data Flows

## 1. New service user onboarding

```text
Referral source / family / local authority
        ↓
Care provider admin team
        ↓
Digital care planning system
        ↓
Care staff mobile app
        ↓
GP / pharmacy / emergency services / local authority where required
```

Key checks:

- Has the lawful basis been recorded?
- Is special category data identified?
- Has the service user/family received a privacy notice?
- Is access restricted to staff with a care need-to-know?
- Are third-party systems under contract?

## 2. Medication administration record

```text
GP / pharmacy
        ↓
Care provider medication system
        ↓
Care worker records administration
        ↓
Manager reviews exceptions/incidents
        ↓
Shared with GP/pharmacy/regulator where required
```

Key checks:

- Is access role-based?
- Are changes auditable?
- Are medication incidents logged securely?
- Is data shared securely?

## 3. Staff recruitment and employment records

```text
Applicant
  ↓
HR/recruitment mailbox
  ↓
HR system / payroll / DBS checks
  ↓
Manager review
  ↓
Archived or deleted according to retention schedule
```

Key checks:

- Is candidate data retained for a defined period?
- Are DBS documents handled securely?
- Is payroll provider assessed as a processor?
- Is the staff privacy notice clear?

## 4. CCTV incident review

```text
CCTV camera
  ↓
Local recorder/cloud CCTV platform
  ↓
Manager access after incident
  ↓
Disclosure to police/regulator/insurer where lawful
```

Key checks:

- Is CCTV signage visible?
- Has a DPIA been completed?
- Is footage retention limited?
- Are access logs enabled?
