# Reference Guidance

This project uses public UK guidance relevant to care-sector data protection, governance, cyber security and compliance.

## ICO sources

1. ICO Accountability and Governance
   - https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/accountability-and-governance/
   - Used for: accountability, documentation, contracts, DPIAs, DPO responsibilities, governance oversight.

2. ICO Guide to Accountability and Governance
   - https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/accountability-and-governance/guide-to-accountability-and-governance/
   - Used for: proving compliance, maintaining trust, demonstrating responsibility for personal data.

3. ICO Data Protection Audit Framework
   - https://ico.org.uk/for-organisations/advice-and-services/audits/data-protection-audit-framework/
   - Used for: self-assessment structure and audit readiness.

4. ICO Data Protection Impact Assessments
   - https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/accountability-and-governance/data-protection-impact-assessments-dpias/
   - Used for: DPIA screening, necessity/proportionality, risk assessment and mitigation.

5. ICO Examples of Processing Likely to Result in High Risk
   - https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/accountability-and-governance/data-protection-impact-assessments-dpias/examples-of-processing-likely-to-result-in-high-risk/
   - Used for: deciding when DPIAs are mandatory.

6. ICO Special Category Data
   - https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/lawful-basis/special-category-data/what-are-the-rules-on-special-category-data/
   - Used for: health records, care records, safeguarding records and worker health information.

7. ICO Transparency in Health and Social Care
   - https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/data-protection-principles/transparency-in-health-and-social-care/
   - Used for: privacy notice review and service-user communication.

8. ICO Data Sharing Code of Practice
   - https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/data-sharing/data-sharing-a-code-of-practice/about-this-code/
   - Used for: data sharing governance and agreements.

9. ICO Data Sharing Agreements
   - https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/data-sharing/data-sharing-a-code-of-practice/data-sharing-agreements/
   - Used for: controller-controller and sharing documentation.

10. ICO Lawful Basis for Sharing Personal Data
    - https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/data-sharing/data-sharing-a-code-of-practice/lawful-basis-for-sharing-personal-data/
    - Used for: checking lawful basis before sharing personal data.

11. ICO Information Security Checklist
    - https://ico.org.uk/for-organisations/advice-for-small-organisations/getting-started-with-gdpr/data-protection-self-assessment-medium-businesses/information-security-checklist/
    - Used for: security control prompts for SMEs.

## Care-sector and NHS/CQC sources

1. CQC Regulation 17: Good Governance
   - https://www.cqc.org.uk/guidance-regulation/providers/regulations-service-providers-and-managers/health-social-care-act/regulation-17
   - Used for: governance, accurate records, oversight and data protection retention expectations.

2. CQC: Check the way you handle personal information meets the right standards
   - https://www.cqc.org.uk/guidance-providers/all-services/check-way-you-handle-personal-information-meets-right-standards-0
   - Used for: care provider information security and DSPT expectations.

3. CQC Governance, Management and Sustainability
   - https://www.cqc.org.uk/guidance-regulation/providers/assessment/single-assessment-framework/well-led/governance-management-sustainability
   - Used for: well-led governance and risk oversight.

4. NHS Digital Data Security and Protection Toolkit
   - https://digital.nhs.uk/cyber-and-data-security/cyber-security-services/data-security-and-protection-toolkit
   - Used for: data security and protection self-assessment concepts.

5. NHS Digital DSPT Assessment Guides
   - https://digital.nhs.uk/cyber-and-data-security/guidance-and-resources/data-security-and-protection-toolkit-assessment-guides
   - Used for: National Data Guardian standards and health/care sector assurance.
